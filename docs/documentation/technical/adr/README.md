# Architecture Decision Records

One file per decision, named `NNNN-short-title.md` (for example, `0001-deterministic-orchestrator.md`).

## Template

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem or constraint forces a decision.

## Decision
What we chose.

## Alternatives considered
What else we evaluated and why we rejected it.

## Consequences
Trade-offs across autonomy, accuracy, latency, cost, and human oversight.
```
